# v1be lead hero

A Codex skill by [gorkemberkgundogdu-alt](https://github.com/gorkemberkgundogdu-alt) for developing brand-specific website hero concepts at v1be studio.

The workflow starts with a live desktop and mobile audit, develops two concepts, selects a direction, and delivers near-final desktop and mobile comps. Framer implementation requires an explicit user instruction.

## Use in Codex

With GitHub access to this repository, clone it into your Codex skills directory as `v1be-lead-hero`. In a new session, invoke `$v1be-lead-hero` with the prospect's official website URL.

The workflow references `website-lead-audit`, [Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design), [Taste Skill](https://github.com/Leonxlnx/taste-skill), and [Impeccable](https://github.com/pbakaus/impeccable). Install those separately. Live audit requires a browser. Framer work requires the Framer connector and access to the target workspace.
